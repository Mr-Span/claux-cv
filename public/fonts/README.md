# Local fonts

Unmodified WOFF2 files from `@fontsource-variable/ibm-plex-sans`, `@fontsource-variable/space-grotesk` and `@fontsource-variable/jetbrains-mono`, all pinned to version 5.3.0. Exact download URLs, sizes and SHA-256 hashes are recorded in `manifest.json`.

Each family includes normal variable-weight `latin` and `latin-ext` subsets. The extended subset covers Romanian Ș/ș in Claudiu Șpan's identity. Weight ranges are IBM Plex Sans 100–700, Space Grotesk 300–700 and JetBrains Mono 100–800. CSS retains the existing family names and uses `font-display: swap`; no runtime font service or font package dependency is required.

All three families use SIL Open Font License 1.1. The accompanying `*-LICENSE.txt` files are copied from each pinned Fontsource package's `LICENSE` file at `https://cdn.jsdelivr.net/npm/@fontsource-variable/{family}@5.3.0/LICENSE` and retain the original copyright notices.
